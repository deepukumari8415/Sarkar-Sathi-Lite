# 🇮🇳 Sarkar Sathi AI (Offline)

## Overview
Sarkar Sathi AI (Offline) is a web-based assistant that helps users get basic information about government services and schemes without using any external API or internet connection.

The chatbot works completely offline using a built-in knowledge base and keyword matching.

---

## Features

- Offline AI-style chatbot
- No API required
- Fast keyword-based search
- Government scheme information
- Aadhaar guidance
- PAN Card guidance
- Passport information
- Driving Licence information
- Scholarship information
- Government Jobs
- Emergency numbers
- Responsive user interface
